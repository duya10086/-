# 无界 · 开放世界引擎 V1.0

一张不绑定任何世界观的 GM 卡。卡片里没有国家、没有神明、没有力量体系——这些全部在开局时生成，所以同一个卡可以跑玄幻、仙侠、都市、历史、悬疑灵异、科幻、游戏、末世，互不干扰。

## 导入

SillyTavern → 顶部「角色」面板 → 右下角「导入角色」→ 选 PNG，或把 PNG 直接拖进浏览器窗口。
导入后会同时带上世界书（名字：`无界 · 通用规则库`），无需另外导入。

## 开场白里写了什么

开场白是一张说明书，425 字，五块：

1. **一句话定调**——没有预设世界，三项选完、两栏写完就开局；拿不准的留默认，写不出的留空
2. **面板**——模式切换 + 三组选项 + 两栏（角色设定／开场白）+ 开始创世
3. **两栏怎么填**——「角色设定」写你的主角，「开场白」写这次从哪开始，一句就够
4. **拿到的东西**——宪法、你的主角、我补了什么，最后一段开场白；从它最后一句往下接
5. **随时能说的话**——节奏微调、看结构、推演、校对、合上剧本，以及括号约定

这套骨架是从你自己那张 `Nexus自定义世界`（v2.1，Downloads 里那份）的开场白借的：它先让玩家选旅行模式，再填词条。我把「选模式」留下来，把词条表换成面板上的按钮。

## 三种模式：造物主是标准版

| 模式 | 你给什么 | 差别 |
|---|---|---|
| **五项都我定**（造物主） | 三组选项 + 两栏自由写 | 标准版，其余两种都是它的简化 |
| **只给题材**（探索者） | 一个题材，或什么都不给 | 只剩题材一组，其余全由它定 |
| **看世界转**（群像） | 和造物主一样 | 参数照旧，只多一条镜头规则 |

按钮在面板最上面。切到「只给题材」，后面几组会收起来；切回来又都在。参数本身不会因为换模式被清掉。

### 造物主：三项选项 + 两栏，选完写完就开局

默认就是这个。三组选项全部铺在一页上，每组第一个已是默认值（金手指默认「无」——不出意外就没有外挂），**什么都不点、什么都不写也能直接开始**：

```
题材 玄幻 ← 默认（可多选，点几个＝融合）
金手指 无  ← 默认
基调 爽文 ← 可多选
角色设定（可空）  ← 自己写：姓名／性别／性格／外貌
开场白（可空）    ← 自己写：这次从哪开始
```

想改就点别的、写两栏。点「开始创世」，它发出这一行：

```
【创世】题材=都市＋校园＋仙侠；金手指=老爷爷；基调=爽文＋温情；
角色设定=下山的年轻高手，被安排进大学当保镖；
开学第一天，保护对象把他当成新生
```

题材那栏点了三个，参数串里就是「都市＋校园＋仙侠」——它会照《校花的贴身高手》的路子融成一个世界。

收到后第一屏固定四节，一节不多：**世界宪法 → 主角（含读出的主线·暗线）→ 我补了什么 → 开场白**。**不再有「先给三个方案让你挑」这一步**——那套删了，选定就是选定。

不合心意又想偷懒，点右边的 **随机**：每组摇一个值（不碰两栏），一次换一套。

### 两栏：角色设定与开场白

这两栏照的是你那张自定义世界的【个人信息】与【初始剧本】，让你自己写，不做按钮——**主角长什么样、这一局从哪开始，只有你自己写得准**。

**角色设定（可空，最多 120 字）**——你的主角。姓名／性别／性格／外貌，想到什么写什么，写多少算多少：

> 沈砚，男，二十岁，闷嘴葫芦，左眉一道疤

写了的照原样落地，不许它改写；没写的（年纪、靠什么吃饭、随身、一条关键关系）由它补，补的进「我补了什么」给你推翻。

**开场白 · 从哪开始（可空，最多 160 字）**——初始剧本／钩子，这次从哪开始写：

> 被逐出师门的少年，正跪在山门外的雨里

写了就以它为开场正文第一句的起点：你给的时间、地点、处境照用，在此之上展开成戏。留空才由它自己挑开局位置。

两栏都和选项冲突时保留你的原话，把冲突写进宪法。另外每组末尾那个「自定义…」是第三回事：它只替换**那一项**的值（16 字以内，回车即开局）。

### 另外两种：只是造物主的简化版

**只给题材**——面板只剩题材一组（两栏留着，可写可不写）。发给模型的是：

```
【创世】题材=仙侠；开场白=开局就被逐出师门；模式=探索者
```

其余它自己定，写进宪法与主角那一节让你能直接改。规矩只有一条：开头三句内必须落到一个具体的人、一个地点、一个眼前的麻烦。

**看世界转**——参数和造物主完全一样，只在末尾多一个 `；模式=群像`。它多给的是一条镜头规则：先给宪法，再给三到五人名单（各自想要什么、被什么压着、跟谁有旧账），然后镜头在多人之间移动——**主角不在场的戏照样演，主角不知道的事照样发生**。说「我是其中一员」给你一个位置但不给全知视角；说「观察者」就只写世界。

三种模式共用同一套宪法、状态栏与边界，主线暗线都由它从设定里读出，差别只有「少要几项」和「镜头怎么摆」。

### 金手指：六个预设 + 自定义

网文开局第一件事就是交代外挂，所以它单独成组：

| 选 | 给什么 | 附带什么麻烦 |
|---|---|---|
| 无（默认） | 什么都不给，全靠自己 | 慢，但每一步都是自己挣的 |
| 系统 | 界面、任务、奖励、兑换 | 有惩罚条款，任务专挑你不想做的 |
| 老爷爷 | 随身导师，指路、教招、见过世面 | 只给指点不给力量，且有他自己的目的 |
| 面板属性 | 看得见自己的数值与进度 | 看得见不等于改得动，数值也暴露短板 |
| 模拟器 | 先试错，再落地 | 试错要交学费，模拟里死过会留下痕迹 |
| 先知 | 知道剧情走向（重生／剧透流） | 你一介入，知道的那部分就开始失真 |

「无」排在第一位、是默认值——不出意外就没有外挂。不管选哪个，它都是**设定不是台词**：不许第一段就展示或解释，由剧情逐步显形；给便利也给麻烦，且不能直接解决主线矛盾。选「无」时，它不会偷偷补一个。

### 角色设定：自己写，不做按钮

以前这里是「少年／少女／成年男子…」和「废柴／赘婿／重生…」两组按钮，现在换成一栏自由写（照参考卡的【个人信息】）。**主角长什么样、是什么样的人，按钮猜不准，只有你自己写得准**：

> 沈砚，男，二十岁，闷嘴葫芦，左眉一道疤
> 被逐出师门的少年，师父临走只说了一句「别回来」

写多少算多少：写了的照原话落进「主角」那一节，不许改写、不许换成模板；没写的由它补（年纪、靠什么吃饭、随身一件东西、一条关键关系），补的进「我补了什么」给你推翻。**它最在意的人或最抬不起头的那件事，引擎会拿来当暗线**；开场白里他正被什么追着，就是主线。

### 第一屏：四节，开场白是第四节

参数发过去之后，它不会再问一句、也不会摆方案，直接按这个顺序出完就停：

```
▍世界宪法        六项，短句
▍主角            按你写的「角色设定」落地；跟一行「主线 · 暗线」（它读出来的，各一行）
▍我补了什么      三到六项，每项可一句推翻
 开场白 + 状态栏  正文二百到三百五十字，后附这一屏的状态栏
```

开场白的要求写在系统提示里，五条：

1. 第一句就给时间与地点，具体到能推门进去；三句之内出现一个动作或一件具体的东西。
2. 必须有一个正在发生的麻烦（催租、追捕、旧友求助、体检报告、停电、尸体、任命书、一个打错的电话），写清时间、原因与当下的压力。
3. 贴着身体与感官写，不介绍设定、不总结世界、不复述参数，不写「你醒了」「你的故事开始了」。
4. 结尾停在你能立刻接手的地方：一句问到脸上的话、一个递过来的东西、一记敲门声。问句必须是剧中人问的，不是旁白问「你要去哪里」。
5. 不替你做决定、不说话、不表态——只把你放到那个位置上。

「开场白」那栏写了字的话，正文第一句就落在你写的位置上——**从哪开始写由你定，怎么展开交给它**。没写它就自己挑一个。写完之后：开场白最后一句就是接口。想接就写「我推门进去」「我问他要多少」，不想动就写「我坐着不动，看他怎么办」——后者照样推进，世界不会等你。

### 我补了什么

开场白之前那一节，列的是它替你定的东西：

```
我补了什么：靠什么吃饭 港务局挂名的听铁匠，一单三枚铜子
｜短板 听多了会耳鸣到听不见人说话｜关键关系 工头老周，半个师父半个债主
想改哪条直接说。
```

不合意就说「名字换成…」「旧伤不要」，它照改，不重来、不道谢。这是从参考卡借的：**先替你填，再告诉你填了什么**——比你先把人物写一遍省事，也比闷头替你决定安全。

### 五项各自管什么

取值用的是网文自己的名词，不是文学课的标签：频道、金手指类型；两栏是你自己的话。

| 项 | 可选值／写什么 | 网文里对应什么 |
|---|---|---|
| 题材（可多选） | 玄幻 / 仙侠 / 都市 / 历史 / 悬疑灵异 / 科幻 / 游戏 / 末世 | 频道：读者一看就知道该期待什么，**连带布景、力量体系、资源怎么争**。选几个就是融合 |
| 金手指 | 无（默认）/ 系统 / 老爷爷 / 面板属性 / 模拟器 / 先知 | 主角凭什么起跑 |
| 基调（可多选） | 爽文 / 热血 / 黑暗 / 轻松 / 悬疑 / 温情 / 史诗 / 日常 / 荒诞 / 治愈 | 叙事温度，也决定代价收多狠。选几个＝几种温度同时在 |
| 角色设定 | 自己写：姓名／性别／性格／外貌…… | 【个人信息】：你演的是谁 |
| 开场白 | 自己写：这次从哪开始 | 【初始剧本／钩子】：这一局从哪个时刻、哪个房间开始 |

**题材与基调可以多选**——点一个再点一个，两个都亮，参数串里用「＋」连着（`题材=都市＋校园＋仙侠`）。意思是**融合**：几套元素塞进同一个世界，不是分几个世界。参考《校花的贴身高手》——那本书就是把都市、校园、修真、兵王全塞进一座城：白天在校园上课，暗地里有修真门派与古武世家，主角是下山的高手兼保镖，几套元素共享同一个世界、同一条时间线。融合有四条法则（写死在世界书里）：

1. **一个世界**——所有元素共存于同一世界、同一时间线，不许各演各的
2. **定基调盘子**——第一个题材当底盘（社会长什么样、钱从哪来），后面的往里嵌（都市的公司背后是宗门，学校的社团是门派外围）
3. **力量分层**——各套力量体系可并存但分主次稀稠，别每样都满街都是
4. **冲突跨题材**——主线的对手与事件要横跨两套以上元素（查校园失踪案查到修真门派头上），这是融合的意义

基调多选同理：`基调=爽文＋温情`＝打脸要爽、日常要暖，两个温度同时在，不是轮流。

**主线与暗线不在这五项里**——不让它问你，它自己读：**你写的主角最在意什么，暗线就是什么；开场白里他正被什么追着，主线就是什么**。读完各写一行，跟在主角后面。参考《雷神》：主线超英（夺位、流放、打回来），暗线父子——一个父亲的偏心，两个儿子各自想要的那句认可。《庆余年》：want 是掌权翻案，need 是被那个父亲认下来。

**主线是表面那件事**，负责事件、压力、场面，每三到五轮往前推一格。
**暗线是底下那层关系**，负责人物为什么这么做。引擎被要求：暗线不许用台词点破，只让具体的事显形（一顿没吃完的饭、一句没说出口的话、一次站错边的选择）；收束时主线的高潮必须同时是暗线的摊牌。

### 舞台、力量、代价去哪了

以前这三组要一个个点，其实它们都是题材自带的——**选了修仙，自然就有灵气、境界、灵石争夺、宗门与凡人的百态，这些不用再说一遍**。所以这三组从面板上拿掉了，由世界书写死了解码规则，生成宪法时自己填：

| 你选的题材 | 自带的布景 | 自带的力量与资源争夺 |
|---|---|---|
| 玄幻 | 异界大陆 | 斗气／武魂，靠天赋血脉与功法；功法、丹药、族地被宗门世家把持 |
| 仙侠 | 异界或古代 | 修仙境界，靠灵气与丹药；灵石、灵脉、机缘被宗门与散修争夺 |
| 都市 | 现代都市 | 异能觉醒或科技造物；名额、情报、渠道被机构与灰色地带把持 |
| 历史 | 古代王朝 | 武道真气或无力量；官职、田产、军功被门阀与官场把持 |
| 悬疑灵异 | 现代或近代 | 无力量或不完整力量；代价落在心智与名声上 |
| 科幻 | 未来星际 | 科技义体，靠能源与改造；算力、补给、许可证被公司把持 |
| 游戏 | 规则化的世界 | 数值化力量；副本、装备、复活机会被公会与规则把持 |
| 末世 | 现代废土 | 异能或无力量；食物、药、弹药、安全区被幸存者团伙把持 |

代价（用力量收什么费）由**题材＋基调**定，也不用你点：爽文／轻松＝近乎免费，只算修炼成本；热血＝关键时刻要付出；黑暗／悬疑＝反噬或天谴（失控、折寿、失忆、人性）；温情＝账单小但一直在。

想推翻这层默认，在自定义栏里写一句就行（「力量不是灵气是香火」「代价是记忆」），原样落地。

### 参数怎么读：拿经典网文对一遍

| 项 | 它真正决定的 | 网文里的位置 |
|---|---|---|
| 题材 | 频道＋布景＋力量＋资源争夺（一个顶三个）；**可多选＝融合** | 仙侠＝《凡人修仙传》的灵气灵石与宗门；都市＋校园＋仙侠≈《校花的贴身高手》的校园修真 |
| 金手指 | 主角起跑的加速度 | 无＝凡人流；老爷爷＝药老（斗破）；先知＝知道剧情走向（穿越重生流）；系统＝任务与惩罚（系统流） |
| 基调 | 叙事温度，也决定代价收多狠 | 爽文（斗破，账单轻）／黑暗（道诡异仙，反噬）／轻松（庆余年贫嘴）／史诗（遮天的命运重量）／日常（生活流） |
| 角色设定 | 你写的这个人，直接进「主角」那一节 | 沈砚式一句话人设；写「少年天子」它也不会给你换成萧炎 |
| 开场白 | 这一局从哪个时刻开始 | 初始剧本／钩子：「被逐出师门的少年跪在山门外的雨里」=《斗破》退婚开局 |

一条参数串念出来就是一句话简介：**（角色设定里的这个人），在（题材自带的世界）靠（题材自带的力量＋金手指）做（主线），基调（××），其实在讲（暗线）**。

差异集中在三个开关上：**题材＋金手指**＝怎么变强；**基调**＝赢了要付什么；**角色设定＋开场白**＝这部戏在讲什么（主线暗线就是从这两栏读出来的）。

四组现成配方（近似念法，不是严格归类）：

| 参数 | 出来的书 |
|---|---|
| 玄幻·老爷爷·爽文 ＋「萧炎式少年，天赋被夺」「三年之约，退婚当日」 | 《斗破苍穹》：退婚开局，捡个老爷爷，一路打回去（题材自带斗气异火与族地之争） |
| 仙侠·无·爽文 ＋「资质平庸的穷小子」「七玄门山门前，测灵根那天」 | 《凡人修仙传》：靠算计与灵石一寸寸往上爬（题材自带修仙境界与灵石） |
| 悬疑灵异·无·黑暗 ＋「借尸还魂的值夜者，档案员周明瑞」「老城区的连环失踪案派到手上」 | 《诡秘之主》：借身份查案，每查深一层就疯一点（基调把代价调成反噬） |
| 历史·先知·轻松 ＋「现代青年穿成私生子，嘴上不饶人」「进京的马车上，父亲的信刚送到」 | 《庆余年》：权谋是表，父子是里（题材自带官场田产） |
| 都市＋校园＋仙侠·老爷爷·爽文＋温情 ＋「下山的年轻高手，被安排进大学当保镖」「开学第一天，保护对象把他当成新生」 | 《校花的贴身高手》：白天上课暗地修真，几套元素塞进一座城（多选题材＝融合） |

还有一类是故意让它打架：**题材＝仙侠 配 基调＝悬疑**——宪法会写成「所有案子都有合理解释，而合理解释越堆越不对劲」。这类冲突不是 bug，是最好用的开局；想指定「力量不是灵气是香火」就写进角色设定那栏里顺嘴带一句。

### 三幕：借电影电视的分寸

世界书里新加了一条 `[叙事] 三幕与 want／need`，常驻。它要求引擎按幕走，不按字数走：

| 幕 | 要发生的事 |
|---|---|
| 第一幕 建置 | 先用一场定调的冷开场（不必是主线）让人看见这世界疼在哪；再让一件事把你拽上主线，这幕结束时你已经不能回头 |
| 第二幕 对抗 | 中点翻面——从被动变主动，或真相揭开一层，赌注升高；每场戏要有转折：进门谁占上风，出门换人 |
| 第三幕 收束 | 低谷让暗线最痛（主线全输、退路断掉），然后主线高潮与暗线摊牌同时发生 |

用编剧的老话讲：**want 是说得出他想要的（＝主线），need 是他说不出但真正缺的（＝暗线）**。结局允许 want 落空，need 必须达成——或者明确写下「他没能得到」。

引擎被给了五部片子的分寸做参照，只借结构不抄情节：

- 《雷神》want 是王位，need 是父亲一句认可
- 《教父》want 是置身事外，need 是变成他父亲
- 《无间道》两条线互为镜像，谁先认自己是谁谁先死
- 《绝命毒师》want 是给家里留钱，need 是被人当个人物
- 《漫长的季节》主线追凶，暗线是三个人的体面
- 《庆余年》want 是掌权翻案，need 是被那个父亲认下来

对手也被要求写成立得住的人：他那套逻辑在他自己眼里是对的，不是纯粹的坏。

世界层其余的要素（三五个势力、什么稀缺、消息怎么传、普通人的一天、当前矛盾、禁忌）**故意不进面板**：它们每个世界都不一样，做成选项等于把世界框死，交给宪法现场生成。

从你那张 `Nexus自定义世界 v4.0` 借来的三条，已经写进世界书，不占面板：
- **稀缺与日常**——多数匮乏来自分配不是总量；写物价、交通、消息怎么传，别写「繁华」「萧条」。
- **生活线与真相层**——场外几条「被什么压着／想要什么」的线；叙述从不撒谎，骗人只靠镜头选择，收线时前文必须找得到依据。
- **雾中展开**——第一次走到某地才展开细节，不预生成整张地图。

## 元指令

```
/world  查看并改写世界宪法      /recap  三百字前情回顾
/sheet  我的角色档案            /new    另起一个世界
/skip   跳过一段时间            /slow   放慢，多写日常
/fast   加速推进                /ooc    出戏讨论规则
```

不带斜杠的口语指令，直接说就生效：

| 说 | 效果 |
|---|---|
| 看结构 | 幕后：几条线在跑、几条伏笔、各自进度，不泄露后文 |
| 推演 | 先演一段「如果这么做会怎样」，演完退回当下，时间不推进 |
| 校对 | 查最近十轮有没有前后矛盾（时间、地点、伤势、钱、谁知道什么） |
| 合上剧本 | 退回旁观者，只描述不代入 |
| 整理世界书 | 把已确立的设定紧凑列出来 |
| 我补了什么 | 重列开局时替你补的那些项 |

说「暂停」立刻停戏；说「这段不算」会撤回上一轮重写。

另外有个约定：**（括号里的话）只给引擎看**——你可以在里面写「其实他是个私生子，别让任何人知道」，它据此调整，但剧中人不知情；它自己的正文一律不用括号。

## 想固定成某个世界时

引擎默认每次开局重新创世。如果你有一个想长期跑的世界：

1. `/world` 导出宪法，或直接把设定贴给它，让它生成。
2. 在世界书里新建条目：标题写世界名，关键词填世界名 + 主要地名，内容贴宪法，勾选「常驻」。
3. 编辑角色 → 场景（Scenario）改成「故事发生在《XX》……」，这样每次开新档都默认回到这个世界。
4. 想保留多个世界时，不必改卡，用 `/new` 切换，各个存档互不影响。

## 改面板上的选项

面板不是手写的，由 `build/build_card.py` 两张表生成，每组末尾的「自定义…」是自动加的：

```python
PANEL_GROUPS = [                       # 三项选项
    ("题材", ["玄幻", "仙侠", "都市", ...]),   # 自带布景、力量、资源争夺
    ("金手指", ["无", "系统", "老爷爷", ...]),  # 「无」在第一位＝默认值
    ("基调", ["爽文", "热血", "黑暗", ..., "治愈"]),
]
# 角色设定／开场白是两栏自由写（#role / #open），不在按钮表里
MODES = [("造物主", "五项都我定"), ("探索者", "只给题材"), ("群像", "看世界转")]
QUICK_HIDE = {"金手指", "基调"}   # 探索者收起这两组，题材和两栏留着
```

模式按钮的文字、placeholder、按钮标签在 `PANEL_HTML` 与 `setMode()` 里；`QUICK_HIDE` 决定「只给题材」模式下收哪几组。模式本身的行为规则在世界书 `[模式]` 那一条。

加减选项、加一整组新参数、改组名、调顺序都改这里——参数行的顺序由页面上的 DOM 顺序决定，脚本自动跟着变；组名同时就是参数串里的键名，改名要顺手改世界书 `[面板] 创世参数串` 的解读规则。

两栏文本框（`#role`／`#open`）在 `PANEL_HTML` 末尾；它们和每组末尾的「自定义…」怎么被解读，看世界书 `[面板] 创世参数串` 的第三条。

改完跑：

```bash
cd build
python build_card.py    # 重出 JSON
python make_cover.py    # 打包 PNG
```

把新 PNG 拖回酒馆即可。授权按文件名记——**只要还叫 `无界-开放世界引擎-v1.0.png`，就不用重新允许**；改名了才需要再点一次。

## 加自己的规则

世界书 `无界 · 通用规则库` 里有 24 条，按用途分了前缀：

- `[核心]` 宪法与优先级底线、稀缺与日常
- `[规则]` 力量与代价三问、力量体系生成器
- `[GM]` 三层状态、事件、NPC、信息差、后果、时间跳跃、冲突裁定、懒加载、玩家档案、生活线与真相层
- `[叙事]` 活人感、亲密与边界、三幕与 want／need（电影骨架）
- `[UI]` 状态栏
- `[元]` 指令表、跑偏修复
- `[类型]` 体裁适配包
- `[面板]` 创世参数串（含自定义、金手指、模式的解读）

加新规则就照这个格式复制一条：标题带前缀，非必读的填关键词、别勾常驻，避免挤占上下文。

### 手机连电脑上的酒馆

已经替你配好了，手机连**同一个 WiFi**，浏览器打开：

```
http://192.168.31.158:8000
```

改动写在 `D:\Git\SillyTavern\config.yaml`（原文件备份为 `config.yaml.bak-20261122`）：

```yaml
listen: true                      # 原来 false，只允许本机

  - 192.168.31.0/24               # 新增：允许本机所在网段
```

**安全提醒**：现在是「同 WiFi 内无密码可访问」。如果你家的 WiFi 有别人能连（合租、公司、宿舍），建议开一层密码：

```yaml
basicAuthMode: true

  username: user
  password: 自己设一个
```

改完重启酒馆生效。不想让局域网访问了，把 `listen` 改回 `false` 即可。

### 卡片为手机做了什么

- **开场白按窄屏重排**：最长一行 20 个全角字，360px 宽的手机也不会断行。原来那种 `════════ 标题 ════════` 的框线在手机上必然折成两行，已全部换成 `▍`、`──`、`·` 这类行首标记。
- **缩进用全角空格**：酒馆的消息区会把连续半角空格压成一个，普通空格做缩进在手机上会全部顶格。改用 `　`（U+3000）后层级才立得住。
- **状态栏按窄屏写死规则**：一项一行，不并排多栏、不用表格、不靠空格对齐，单项超 18 字自动折行。这条同时写进了 system prompt 和 `[UI] 状态栏格式` 条目，模型每一轮都会遵守。
- **零扩展依赖**：不用酒馆助手，手机上不用装任何前端模板，纯文本就能跑。

### 手机上的操作差异

- 切换开场白：左右滑动消息区，或点消息上方的 `1/3 2/3 3/3`。
- 导入卡：手机浏览器一般不能直接拖拽，用「角色」面板右下角的导入按钮选文件；安卓也可以把 PNG 先存到手机再选。
- 输入框在 iOS 上会被键盘顶起，酒馆自带处理，如果挡住了就轻点消息区空白处收起键盘。

## 酒馆助手（JS-Slash-Runner）

**其实早就装了，只是入口藏得深**，所以看起来像没有。已经帮你从 4.8.7 升到 **4.12.2**。

入口两条，任选：

| 路径 | 位置 |
|---|---|
| A | 顶栏**立方体图标**（鼠标悬停显示"扩展程序"）→ 往下滚，最底部「酒馆助手」 |
| B | 顶栏齿轮「用户设置」→ 左侧「扩展」→ 最底部「酒馆助手」 |

打开后有五个分页：**渲染 / 脚本 / 工具 / 优化 / 开发**。常用的三个：

- **渲染**：`启用渲染器` 打开后，消息里符合条件的代码块会被渲染成前端界面（HTML 卡、状态栏、图表都靠这个）。渲染深度设为 0 表示所有楼层都渲染。
- **脚本**：管理 JS 脚本，脚本可以读写变量、监听楼层、画 UI。
- **工具**：提示词查看器、变量管理器、日志查看器——排查"为什么模型没按设定说话"就靠它。

另外魔法棒（输入框左侧的笔刷图标）菜单里，最后一项「提示词查看器 / 变量管理器 / 日志查看器」也是它，不用进设置就能开。

**这张卡用它做两件事**：渲染开场参数面板、渲染以后可能加的 HTML 状态栏。除了这两处，正文全是纯文本，不开渲染器也能玩。

## 关于 token

**开场白 425 字**，面板 HTML（10.7KB）走角色正则，不进上下文——省掉每轮约 3500 token。开场白多出来的字是用法说明，只算一次，换来的是不用再去翻文档。

常驻内容（system_prompt + 每轮指令 + 14 条常驻世界书）约 7423 字，其余 10 条按关键词触发（含 `[面板] 创世参数串`、`[模式]`）。相比参考卡把上百条全设常驻的做法轻很多，但仍是"重卡"——建议用支持长上下文的模型，且把上下文设到 16k 以上。

## 设计取舍

- **状态栏是纯文本**，不依赖酒馆助手或任何扩展，任何客户端都能跑。想要参考卡那种 HTML 终端界面，需要装酒馆助手再另做一套前端模板。
- **没有写死任何世界内容**，代价是开局多花两三分钟创世；换来的是同一个卡能反复用在不同世界观上。
- **不给数值系统**。需要时它会问你要不要加，加也只加 3~6 项，避免变成刷数值游戏。
- **参数优先，但不填表也能开**。三组选项都有默认值（金手指默认「无」），两栏留空也行，零输入点一下就能开局；它先替你补，再把补的逐条列出来给你推翻——比让你先写一份人物设定省事，也比闷头替你决定安全。角色设定与开场白改成自由写，是因为按钮猜不准「你是谁」和「从哪开始」。
- **不做「先给三个开头让你挑」那种引导**。试过，删了：它把选择变成了抽签，抽出来的东西总差一点。参数表看着笨，但每一下都是自己按的。
